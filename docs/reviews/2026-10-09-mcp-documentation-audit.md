## 已核对的现状

- `apps/backend/src/mcp/tools.rs` 定义五个只读工具。原页面多个“四个工具”、四项导航和键盘 End 索引均已漂移；修正为数据驱动数量与最后一个工具。
- `apps/backend/src/mcp/navigation.rs` 的接口详情有三个独立分页标记；环境只过滤请求资料引用。请求原文续读可通过 `source_record` 固定调用记录，来源变化时必须从头读取。补齐参数、输出字段和续读示例说明。
- 当前 `read_interface` 不返回旧教程描述的整份 facts、原始 samples 或目录浏览工具；不能根据旧的 `nexofolio_catalog`、`nexofolio_folder_endpoints` 等工具名接入。
- `modules/access/adapter/src/mcp_tokens.rs` 已有管理员颁发/撤销、哈希验证、过期与当前账号项目权限校验。`apps/backend/src/bin/admin.rs` 将颁发结果写入保护文件，不回显原文。没有用户自助凭证管理路由。当前生成器复用 `session_crypto.rs`，前缀实际是 `nfi_`，旧文档的 `nfm_` 不能作为输入校验契约。
- Token 当前继承账号所有有效项目访问权限，不是每个 Token 选择项目的独立范围。
- 原始 GET `/docs/mcp` 只返回 SPA 壳，普通不执行脚本的 Agent 得不到安装正文。现新增开发/预览静态响应、构建产物 `mcp.html` / `mcp.md`，以及生产 Nginx 文档路由示例。
- 服务使用 Streamable HTTP 与自定义 Bearer Header；没有完整 OAuth 发现/浏览器授权流程。配置模板只面向支持自定义 Header 的客户端，具体客户端是否可用仍需真实接入验证。
- 根目录旧设计文档 `NexoFolio/mcp-documentation.md` 仍描述旧工具和未验证的 npm 客户端，应由后端文档维护时标记历史设计或更新。本轮未修改后端仓库。

## 场景与可验证输出

用户要求：为商用订单管理系统测试环境的客户端准备“创建技术咨询单”请求，暂不发送。

1. 确认 project_id、environment_id、客户端范围。当前无法按项目名称发现授权项目，需由平台提供 ID。
2. `search_interfaces` 根据已有名称/用途和路径匹配，确认唯一目标；空页需区分未采集、查询不匹配与读取不完整。
3. `read_interface` 分别遍历 fields/links/request_materials；用实际 example_id、environment_id 和 source_record 读取完整请求资料。输出 URL、方法、Header、query、正文采集状态和缺口，而非按 POST 猜 body。
4. `trace_dependencies` 接受用户声明的当前业务认证和已知字段位置/路径，返回有依据的来源与未解决项；不强制把观测关系解释成前置业务调用。
5. `read_field_values` 获取字段原始类型和值、来源与环境；完整观测值不等于完整业务枚举。
6. 输出请求草案、参数来源表、引用的环境/调用记录/时间、明确缺口以及是否仍需补充资料。本轮文档模拟没有访问真实业务接口，不声称验收已完成。

建议将工具调用审计底座先放到服务端；再开放仅能查询本人或项目授权范围的只读工具。调用审计按工具调用记账，不把一次 HTTP 请求简单等同于一次业务工具调用。不记录凭证明文；完整工具返回正文已有来源存储，审计可引用其 ID，不需复制一份原文。MCP 端不调用模型，模型 Token 使用量应由实际 Agent 客户端归集，不能由返回字节数冒充。

## 一句话安装的边界

文档链接可用作开场，但完成接入还需要实际 MCP 服务 URL、支持相应传输/认证方式的客户端、用户凭证授权和真实工具读取。当前自助凭证功能未完成，不伪造 OAuth、npm 包或自动生成凭证。云端 Agent 不能访问用户本机 127.0.0.1。

上线须一并安装前端 Nginx 新文档 location；否则 `mcp.html` 产物不会自动成为 `/docs/mcp` 路由。MCP 本身的网关映射属于后端部署集成，不由本轮文档修改擅自确定。

参考：[MCP 工具](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)、[Streamable HTTP](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)、[授权发现](https://modelcontextprotocol.io/specification/2025-11-25/basic/authorization)。
