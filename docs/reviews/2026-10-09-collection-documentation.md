# 录入文档通俗化更新

本轮只调整前端文档、演练辅助功能和相关校验，后端及录入规范文件未修改，未发送真实录入请求。

- 依据当前 `contracts/collect/v1` 核对：规范为 1.1.0，包含正文 `partial`；前端固定副本和下载 ZIP 与后端清单哈希一致。
- 将阅读路径改为“先选用途 → 了解资料去向 → 四步演练 → 按需展开字段 → 处理回执与重试 → 下载规范”。浏览器用户优先选择 Fetcher；自建工具才需要 JSON/API；MCP 用于读取。
- 明确录入、结构提取、整理候选、审阅应用的区别。原始事实可查看，整理后的说明和目录须应用后进入现行知识；上传不等于 AI 整理完成。
- 当前实例 API 地址自动填写。可从已选项目上下文带入项目与环境，示例编号由页面生成；未选择的项目/环境和业务内容明确为示例。载入示例不会发请求，用户编辑过的 JSON 不因上下文变化而被覆盖。
- 补齐 Header 示例、五种正文状态、空对象与没有正文的区别，以及 multipart 摘要不含文件字节的边界。
- 强调 HTTP 200 可能有部分拒绝；须核对批次、记录 ID/下标后清理已接收项。失败项保留原因，临时错误用原批次重试，修改数据使用新批次，不重发已接收部分。
- 新增“交给 Agent 开发”及可复制开场，动态填写当前文档、API、完整参考和规范包地址；已有项目上下文时自动附带定位信息。说明先开发和使用虚构数据，未经明确要求不做真实录入。
- `/docs/api` 首次 HTTP 响应和 `/api.md` 提供无需 JavaScript 的完整说明，开发/预览与生产产物同时覆盖；构建新增 `api.html` / `api.md`，生产须同步对应 Nginx 文档路由。
