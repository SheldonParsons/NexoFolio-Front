# 首页交互 3D Logo 接入验收

本轮只接入前端首页，保留之前未提交的首页代码，不修改登录接口、不提交或推送。

## 交付基准

使用 `nexofolio-elastic-coupled` 的 ELASTIC INTERACTION / 03 完整模块，SHA-256 为 `400d75e4cf71c14c0bd3e5649facab2e8b207074ba0f69cc3fc0c3cd53974212`，复制后与原件一致。没有更换独立弹簧算法、镜头或材质。原始可读逻辑和双向接触解算器保存在 vendor 目录。

新增组件负责：部署前缀、类型、异步卸载保护、15 秒加载超时、WebGL 初始化/上下文丢失回退，以及页面历史缓存恢复。Canvas 的 touch-action 设置为 pan-y pinch-zoom，触屏优先保持纵向页面滚动，横向拉扯保留。

## 视觉与限制

实际首页 Canvas 导出到本机 artifacts/home-3d-canvas.png，已查看：黑色表面、中性轮廓反光、无白色底板，透明画布叠在 #000 页面上。未进行降分辨率处理。
本轮 Ego 浏览器的全页截图接口持续超时，不能提供新的完整页面截图证据，也未将旧截图作为本次结果。没有承诺真实手机帧率、所有 GPU 或所有浏览器均已验证。
主要交互已通过真实首页鼠标和触摸模拟操作检查；异步卸载、加载失败和 WebGL 回退使用专门故障注入。测试注入只作用于浏览器测试页，没有写进产品。

## 部署

模块与静态图随 dist 复制，独立 ESM 约 1.9 MB，不需要运行时素材服务。继续使用原有 Nginx 静态部署方案。后续替换模块应更新版本路径或缓存策略，同时复核指纹和兼容性。
