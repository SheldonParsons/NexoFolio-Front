## 当前边界

- 没有接入真实禅道、后端登录、项目同步或接口知识数据。待接入页面没有伪造业务结果。
- 401、超时等由请求层契约测试验证，尚不等于真实登录恢复链路验收。
- 输入处理有组合输入保护；未验证具体操作系统中文输入法的完整操作流程。
- 当前浏览器验证范围为 Chromium；未宣称 Safari/Firefox 或所有图标组合均已覆盖。
- 验证的是本机构建、真实本机 Nginx 容器和页面交互，不代表已经发布到业务服务器。
- 远程 CI 状态以 GitHub 实际运行结果为准，不以本地检查代替。
