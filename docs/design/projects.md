CSS 过渡沿用 cubic-bezier(.22,1,.36,1)，图标使用 Morphicons 的 snappy 弹簧，支持反向中断；减少动态效果时关闭位移、旋转与持续装饰动画。项目进入 2 秒与登录 3 秒时长不变。

查询仍采用 120ms 延迟进度、250ms 防抖、输入法保护和请求取消；已有结果在请求时暂不可点击。失败保留条件并提供重试，数据减少时回到有效末页。样式集中在 projects.css，品牌块封装为 ProjectIntro.vue，页面负责组合。

## 最近访问与返回恢复

- 最近访问和全部项目位于同一滚动容器；没有历史不占位，查询或权限筛选生效时隐藏最近分组。
- 分页只统计全部项目，最近分组允许项目重复出现。
- 详情准入通过且导航成功后才记录。最多保存 20 个 `{id, visitedAt}`，最多展示 3 个。
- scope 包含规范化 API 地址、Mock/Live 和用户 ID；不持久化项目名称、接口内容或权限。
- 使用当前新列表或最多 3 个并发详情读取确认名称与权限。403/404 删除历史，临时失败保留历史但不显示未经确认的项目。点击最近项目仍重新核对详情。
- 进入时新发现的 403/404 同样立即移除该快捷项。存储不可用不阻止正常进入。
- 查询、权限、分页和滚动位置使用按 scope 隔离的内存快照。返回重验数据，最近行就绪后恢复位置，避免高度不足时截短滚动值。
- 退出清理内存快照；快照代次避免旧页面卸载时把已清除视图写回来。

## 进入项目

行立即反馈忙碌并防重复。详情核对权限成功后播放全屏 Logo＋字标流光，固定 2000ms，含最后 200ms 淡出。路由在遮罩下加载，动画不因目标数据慢而延长，结束后由目标页面显示真实加载或错误。

拒绝访问在列表原地显示说明并恢复焦点。401 清会话并引导登录。导航失败、组件卸载和旧回调不会结束新的转场。登录继续固定 3000ms；其他未特别指定的导航随实际准入和页面模块加载结束。

## 数据契约与开关

```ts
interface Project {
  project_id: string
  name: string
  status: string
  can_access: boolean
  access_state: 'allowed' | 'denied' | 'unknown'
  reason_code: string | null
}
interface ProjectPage {
  items: Project[]
  page: number
  limit: number
  total: number
}
```

现有 `GET /v1/projects?page=1&limit=10` 和 `GET /v1/projects/{UUID}` 保留，列表顺序不由前端重排。项目来自后端禅道同步，前端不提供同步或创建写入。

以下是拟新增查询契约，尚未宣称后端已实现或部署：

```ts
interface ProjectListQuery {
  page: number
  limit: number
  q?: string // 按项目名称搜索
  access_state?: 'allowed' | 'denied' | 'unknown'
}
```

新接口 total 必须是过滤后的总数。默认每页 10 条；Mock 对全部 18 个虚构项目过滤后分页，覆盖各类权限、长名称和未知状态。

| 配置                                 | 行为                                            |
| ------------------------------------ | ----------------------------------------------- |
| 开发默认 / VITE_PROJECTS_SOURCE=mock | 全集合 Mock 查询，仍需正常登录守卫              |
| 生产默认 / VITE_PROJECTS_SOURCE=live | 旧接口只发 page/limit；搜索与权限筛选禁用并说明 |
| live + VITE_PROJECTS_QUERY_API=true  | 后端确认部署后才启用 q/access_state             |

VITE 配置在构建时确定；真实服务错误不会切成 Mock，也不会静默降级成本页搜索。

## Header 与图标反馈

AppIcon 提供 activeName/active 两个显式状态参数，保持同一个 MorphIcon 实例来进行路径插值。useIconInteraction 将事件绑定在整个按钮、搜索框或项目行上，区分鼠标与键盘焦点，避免点击后图标黏在 hover 端点。

导航使用网格到面板、日月使用对应活跃形态、退出使用开门形态、文件夹开合、分页由短箭头展开，清除按钮补充圆形关闭形态。状态徽标保持静态。图标遵循 prefers-reduced-motion，减少动效时即时换形。详情见 [Header 与图标验收](../verification/2026-09-14-header-icons.md)。

## 项目行方格反馈

当前机制参照任务 `019ea645-3dc4-7fe0-93f0-811ddc3462f8` 对应的最新项目源码：

- `AsyncTest-Wx/mahjong-package/pages/game/game.js` 中的 CLAIM_CELLS。
- 同目录 game.wxml 的 claim-cell 列表与 game.wxss 的 claim-ignite / claim-flicker。

网页采用黑白的独立方块，保留项目原有点击、准入与导航，不复用提水、震动或交易动作。

- 每格 14px，间隙 3px；根据项目行的实际尺寸计算行列数。
- 从左到右错峰点亮：每格 180ms 从 scale(0) 放大至 scale(1)，单次完成后保持。
- 每格独立执行 420ms 的透明度闪烁；下限由左侧 0.88 渐变到右侧 0.28，与参考效果一致。使用稳定的细微延迟，让各格错开，普通重渲染不会随机换相位。
- 网格最多占项目行 70%，约 1.2 秒点亮到末端后保持该范围，内部各格继续闪烁。首次 hover 前不挂载方格节点。
- 左右两端都使用渐隐遮罩，边缘格子叠加最高 1.6px 的 blur，中心格子保持清晰。
- 移开后暂停并用 200ms 淡出；再次移入只重建背景层，从左重新点亮。键盘 focus-visible 提供等效反馈。
- 浅色为黑格、深色为白格；可访问标记继续使用黑底白勾。减少动态效果时显示静态方格。
- 桌面项目行 56px，手机 64px；文字、按钮位于背景上方，背景不接收点击。

此轮按用户要求只修改和格式化源码，没有运行测试、类型检查、生产构建或浏览器验收，实际效果由用户查看。
