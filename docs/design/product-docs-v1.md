# 产品文档第一版

本轮新增面向产品使用者的静态文档，与项目内的接口知识阅读分开。

## 入口和内容

- `/docs`：NexoFolio 的理念。
- `/docs/fetcher`：Fetcher 的定位、项目/环境绑定与开放接入方式。
- `/docs/workflow`：阅读、重构审阅、发布回退的简要流程。
- `/docs/api`：开放 API 的定位和基本约定，不冒充完整的公共接入手册。
- `/docs/mcp`：面向 Agent 的知识访问方向，明确当前未提供可直接使用的连接配置。
- `/changelog`：按产品筛选的版本时间线。
- `/changelog/product-docs-preview`：文档预览记录；没有虚构 NexoFolio/Fetcher 安装包版本。

顶部“文档资源”的使用文档、MCP、更新日志改为链接，去掉禁用和即将推出状态。原有下载组件、下载服务、首页动画及项目业务接口不变。

## 阅读布局

沿用黑白主题与 56px 通用 Header。文档增加栏目切换、静态全文搜索、左侧文章目录、宽屏页内导航、页面链接复制与前后篇导航。正文和目录内部滚动，保持根视口固定。小屏目录按需展开。

更新日志采用版本/日期侧栏加正文的时间线结构，新增/改进等内容来自 Markdown，截图可选。首版仅提供文档预览记录，Fetcher 产品筛选明确空态。

内容通过 Markdown 文件及独立元数据登记，使用 markdown-it（禁用 HTML）渲染，不依赖文档后端或 CMS。文章 ID 与日志 ID 都体现在路由中，站内链接兼容 BASE_URL。

## 本轮边界

按用户要求，未运行测试、类型检查、生产构建或浏览器验证。页面链接已经接入代码，这不是实际浏览器验收结果。未提交、推送或发布站点。
