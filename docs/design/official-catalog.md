# 正式目录、发布与回退

正式目录入口为 `/projects/:projectId/catalog`，项目列表进入项目后打开此页，沿用原来的 2 秒转场。接口文档和候选目录保留独立入口。沿用现有简单布局。

正式目录读取当前生效版本的组织结构，接口卡片和各环境 revision 引用来自实时接口分页，不从候选快照生成。点击原始成员后使用现有文档 GET 读取该成员、该环境的当前定义。合并组只在成员全部出现在本页时聚合展示；跨页、成员不完整或重复时保留原始记录，不使用代表成员定义覆盖。

待分类由服务返回稳定 ID、system/locked 标志。界面固定置顶，没有改名、移动或删除操作。新建档及当前版本未覆盖的接口直接由服务归入待分类；页面可见时每 5 秒只读更新，重新获得焦点也会更新，隐藏时停止周期请求。此刷新不触发生成、发布或回退。

目录切换接口分页带 `expected_generation`，避免把两个目录版本的数据混在一起。409 显示刷新提示；不会自动覆盖或重试任何写操作。

发布与回退通过同一个显式操作组件完成：打开弹窗先 GET 读取当前 generation，用户确认后才发送 POST。请求包含新的 request_id 与读取到的 expected_generation；网络失败或不确定响应保留原 request_id 和原 body，由用户点“用原请求重试”。未确认的请求按 API 服务地址、用户 ID、项目 ID 隔离保存于 sessionStorage，存储不可用时保留内存重试。切项目、路由卸载取消客户端请求，但不会声称服务端已经取消执行。

409 清除本次尝试，要求用户刷新目录并重新确认。成功响应后重新 GET 正式目录；若成功后的刷新失败，只提供“仅刷新目录”，不再次 POST。401 请求重新登录，403/404 明确展示错误。

版本历史只列已发布版本。初始目录作为独立选项，`version_id:null` 表示全部恢复待分类；恢复动作不删除接口或回滚原始定义。权限沿用项目访问权，无额外角色判断。

本轮不操作 Ego Lite，不修改后端或插件，不提交或推送。前端验证限定自动化测试与类型检查/生产构建，不通过真实 POST 执行发布或回退验收。
