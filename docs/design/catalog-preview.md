# 候选目录预览

入口：项目接口页右上角“候选目录”，路径 `/projects/:projectId/catalog-preview`。共享当前项目页框架，不改整体布局；候选是项目级快照，不需要环境选择。

- 顶部展示候选任务选择器与分页，每页 20 条；额外查询 `status=ready&limit=1` 默认打开最新 ready，无 ready 时打开全部列表首项。若默认 ready 不在当前页，选择器额外保留该任务。
- 任务详情明确标记“候选预览，尚未生效”。展示快照时间、数量、任务状态；pending/running/failed 均保留输入快照且给出状态说明。
- 目录可展开、选择；数量仅统计直属接口。中间列表展示所选目录的方法和路径，右侧展示分类理由及各环境的原始快照定义 JSON，按需展开。没有实时定义替换或模型名称/哈希占据主界面。
- rejected 或父子链接异常时平铺全部候选节点并展示检查问题，不递归遍历环。全部快照接口始终可查，缺失或指向不存在目录的分配归入“待分类 / 未分配”。原始候选 JSON 可展开检查。
- 名称、描述、理由、问题以及定义仅文本展示；没有 HTML 执行或生成/编辑按钮。结构有效的 ready 候选可经用户点击并确认后发布；正式目录入口始终保留。

预览数据读取 `/v1/projects/{project_id}/catalog-previews` 与 `/{task_id}`，沿用内部 Bearer 会话。当前合同为 `catalog-preview/1.3.1`、`documents/1.3.0`、`ingestion/2.2.0`。预览请求验证分页及状态过滤、任务/项目绑定，`published` 表示此候选当前生效。当前生效时显示“当前正式目录来源 · 快照预览”；非生效时显示“候选预览，尚未生效”。401 重新登录，403/404/503 原地报错；不降级为样例。项目、任务切换和卸载取消旧请求，即使迟到返回也不能覆盖新状态。发布操作与回退共用正式目录变更组件，见 [正式目录设计](official-catalog.md)。

2026-09-15 验证：15 项针对性测试通过，覆盖实际 JSON Schema、任意 JSON 定义、绑定拒绝、最近 ready 选择、过期响应、取消、非法环和权限错误；类型检查及生产构建通过。真实后端浏览器验收交由后端任务执行，前端未重复登录；构建结果不等同于实际页面验收。

## 合并组展示

同目录、同方法的有效候选组折叠成模板路径条目；展开后逐个选择原始成员。右侧始终使用该成员的原始路径、分类理由及各环境定义，额外展示合并模板与理由，不替换为代表成员定义。接收时的 `recognized_path` 单独作为机械识别提示，不据此在前端自行合并。

顶部同时显示原始条数和合并后的展示项数（包括独立接口），目录列计数继续表示直属原始接口数。旧候选缺少 `merge_groups` 时按原始列表展示。重叠、重复、未知成员、方法/目录不一致、模板不覆盖、分类异常或结构检查失败时，取消所有合并折叠，保留全部原始条目并给出原因。`logical_interfaces` 如有提供，与计算数不一致时也不折叠。

本次新增 14 项测试，连同原有 15 项共 29 项通过；新旧响应合同、分组异常、独立成员定义以及 Query/Path 参数兼容均已覆盖，类型检查与生产构建通过。此前后端任务完成的 9 目录/31 接口浏览器验收不覆盖本次合并组；新候选的真实浏览器验收待后端任务继续。

后续记录：后端任务反馈真实合并候选 31→20、表格配置 12→1 及成员切换已通过。当用户禁止 Ego Lite 后，不再做该浏览器验收。加入正式发布/回退后的前端测试共 86 项通过，类型检查和生产构建通过；没有在真实项目自动发布或回退。
