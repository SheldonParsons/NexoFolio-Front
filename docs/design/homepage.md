# 首页布局与展示方案

日期：2026-09-14。

## 定位

本版按品牌展示首页实现，访问路径为 `/`；进入工作空间后访问已有 `/projects`。首页使用独立布局，以免展示页和业务工作台互相影响。

主视觉已接入 基于 ELASTIC INTERACTION / 03 的黑色交互 3D Logo：桌面文案与 Logo 左右排列，手机端 Logo 在文案上方。固定镜头整体右倾 8°，开场缩短为约 2.2 秒，随后支持两侧拖拽与双向回弹传力。导航和页脚继续使用原有品牌字标，主视觉模型不反白、不改色。
界面标注“产品预览”，演示区标注“示例数据 / 非实时业务数据”，不将概念设计当成已接入的业务功能。

## 视觉方向

- 页面及浏览器内容底色固定为 `#000000`，不随工作空间的浅深色偏好改变。
- 白色 Logo、米白主按钮、浅灰标题形成层次。少量低饱和颜色只用于示例中的方法和代码类型。
- 首屏采用文案与 3D Logo 配对布局与充分留白，避免卡片堆叠或大面积彩色背景。
- 动效集中在交互触发后的状态切换，支持减少动态效果，无自动轮播或装饰性无限动画。
- 使用现有 Morphicons 图标封装；特殊的知识流程演示独立放在 `features/home`。

## 页面顺序

| 区域       | 内容                                           | 交互                                         |
| ---------- | ---------------------------------------------- | -------------------------------------------- |
| 顶部导航   | 官方图标与字标、产品概览、工作方式、面向 Agent | 页内锚点；进入工作空间                       |
| 首屏       | “每个接口，都值得被理解。”及简短价值说明       | 主入口到项目空间；次入口到示意区             |
| 产品示意   | 业务目录与接口文档窗口                         | 三个阶段切换：发现接口、组织知识、交给 Agent |
| 面向 Agent | 解释分层上下文和 MCP 连接方向                  | 文案说明，不伪造实时连接状态或客户背书       |
| 工作方式   | 收集证据、组织知识、按需理解                   | 三段顺序说明                                 |
| 收尾与页脚 | 完整组合 Logo、再次进入工作空间、预览状态      | 进入工作空间；回到顶部                       |

## Logo 来源与使用

原始文件完整保存在 `public/brand`：

- [完整 Logo](https://asynctest.oss-cn-shenzhen.aliyuncs.com/nexofolio_fetcher/nexofolio-logo-wordmark.svg)
- [独立图标](https://asynctest.oss-cn-shenzhen.aliyuncs.com/nexofolio_fetcher/nexofolio-icon.svg)

用户提供的“完整”和“纯文字”链接相同。`nexofolio-text.svg` 直接提取完整 SVG 的 wordmark 分组，使用该分组的原有字形和位置，不用字体重新绘制。
原稿为纯黑。在黑底页面上通过 CSS invert 展示白色版本，原始文件不改变颜色和形状。页脚采用完整组合，导航采用图标和提取字标的横排组合。
浏览器图标沿用独立图标形状，并针对系统深浅主题设置对比色。

## 代码边界

- `pages/HomePage.vue`：展示页结构与响应式布局。
- `features/home/KnowledgePreview.vue`：仅含本地概念示例的交互组件，不请求业务接口。
- `components/brand/BrandLogo.vue`：统一品牌资产、组合和反白处理。
- `components/brand/NexoLogoHero.vue`：3D 生命周期、加载失败/WebGL 不可用回退、手机纵向滚动；`elastic.ts` 定义模块契约与部署路径。
- `public/nexofolio`：完整 ESM 与同版本黑色静态回退图；`vendor/nexofolio-elastic` 保存可读源逻辑和校验信息。
- `layouts/WorkspaceLayout.vue`：原工作空间布局。
- `app/App.vue`：根据路由 layout 选择布局，维护页面底色标记。

## 验证要求

检查黑底实际计算值、原始/提取 Logo 的加载与比例、三阶段按钮、页内锚点、工作空间往返、375px 手机及横屏布局、减少动态效果和放大文字后的溢出。
生产构建继续输出静态 dist；本轮设计不改变后端接入状态。
