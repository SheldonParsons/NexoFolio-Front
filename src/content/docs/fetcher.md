## 一种官方接入方案

NexoFolio Fetcher 是官方提供的浏览器扩展，用于将授权范围内的接口调用与相关上下文接入 NexoFolio。

它让接入从已有的工作过程开始：浏览业务页面、完成一次操作、查看返回结果，这些过程产生的信息可以成为接口知识的来源。

> Fetcher 是 NexoFolio 的一种官方接入方式。NexoFolio 同样欢迎通过开放 API 接入的其他工具与系统。

## 从项目与环境开始

接入前，先确定采集内容属于哪个项目、哪个环境，以及允许采集的页面范围。

1. 从页面顶部的 **Fetcher** 入口获取扩展安装包。
2. 按扩展中的提示完成安装、登录与采集授权。
3. 将采集范围关联到对应项目和环境。
4. 在授权页面中正常完成业务操作，再回到 NexoFolio 阅读接口资料。

项目回答“这些知识属于哪里”，环境帮助区分不同运行场景下的接口定义。它们共同决定资料的归属。

## 采集之后会发生什么

接入资料会经过处理，形成可以阅读的接口记录。目录尚未覆盖的新接口，会出现在“待分类”中。

采集与重构是不同的步骤。日常采集积累资料；重构在你明确发起后，基于一份快照审阅和整理知识。

对于缺失、截断或无法读取的内容，阅读时需要保留这些限制，避免把一次不完整的观察当成确定结论。

## 使用自己的接入方式

如果你已有采集链路，或希望从浏览器之外的系统接入，可以从 [开放 API 概览](/docs/api) 了解接入边界。

不同接入方式都需要遵守相同的项目归属、环境、授权与数据约定。Fetcher 的存在，不会限制你选择更适合自己的工具。
