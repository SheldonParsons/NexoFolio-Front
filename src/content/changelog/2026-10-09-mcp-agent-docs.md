## MCP 接入更直接

- 新增账号级 MCP 凭证管理：可创建多个独立 Token，设置有效时间区间或无限期，并单独撤销。完整 Token 仅创建时展示一次。
- 凭证页展示当前服务地址、传输方式、协议版本与可访问项目数量。
- MCP 增加项目和环境发现工具。用户可按项目名称和业务目标提问，由 Agent 获取真实 ID；同名时再选择，无需手工查找 UUID。

## 文档可以直接交给 Agent

- MCP 文档按当前环境填写服务地址、凭证入口和安装开场，不再固定使用示例域名或本地地址。
- 录入 API 文档新增“交给 Agent 开发”和可复制话术，自动带入文档、录入地址、规范包与已选项目信息。
- 提供无需执行 JavaScript 的完整阅读入口：`/mcp.md` 与 `/api.md`。网页原链接也可直接返回完整正文。
