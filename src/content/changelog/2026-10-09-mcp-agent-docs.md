## MCP 接入更直接

- 新增账号级 MCP 凭证管理：可创建多个独立 Token，设置有效时间区间或无限期，并单独撤销。完整 Token 仅创建时展示一次。
- 凭证页展示当前服务地址、传输方式、协议版本与可访问项目数量。
- MCP 增加项目和环境发现工具。用户可按项目名称和业务目标提问，由 Agent 获取真实 ID；同名时再选择，无需手工查找 UUID。

## Agent 可以自己选择检索路线

- 支持逐层浏览业务目录，空目录时仍可进入未分类或全部接口。
- 接口可按需看概览，精确字段命中可直接读取完整语义；字段说明与已保存关联可继续指向其他接口。
- 按字段名称或说明搜索所属接口，不预先下载全项目原始样本。
- 请求、响应与来源证据分开读取，完整资料可以按来源版本续读；新增已保存资料的覆盖检查。
- 保留旧接口读取方式，新的工具契约明确读取部分与下一步入口。

## 字段和缺口可以逐层展开

- 字段先读完整语义及少量引用，完整依据和观测值另行读取，原完整字段快照继续可用。
- 覆盖检查先给分类汇总，再按字段或类别展开，区分生成已处理、语义确认与采集缺口。
- 精确来源引用提供请求、响应及上下文入口；引用不完整或失效时再选择样本。
- 参数越界给出具体范围和修正信息，正常续读可沿用下一跳参数。
- 字段树省去叶子节点的空展开入口和重复路径；字段搜索直接指向完整语义，减少重复概览调用与流量元数据，完整资料仍可按需读取。

## 服务更新后可以继续整理

- 后端重启后自动恢复执行租约已过期的运行任务，沿用原轮次和已保存资料，补齐未完成部分。
- 手动停止、已完成、已应用和已废弃的任务保持原状态；缺少兼容恢复资料或正式文档已变化时保留内容并提示处理。
- 已保存内容继续保留，尚未保存的处理批次可能重新执行。

## 文档可以直接交给 Agent

- MCP 文档按当前环境填写服务地址、凭证入口和安装开场，不再固定使用示例域名或本地地址。
- 录入 API 文档新增“交给 Agent 开发”和可复制话术，自动带入文档、录入地址、规范包与已选项目信息。
- 提供无需执行 JavaScript 的完整阅读入口：`/mcp.md` 与 `/api.md`。网页原链接也可直接返回完整正文。
